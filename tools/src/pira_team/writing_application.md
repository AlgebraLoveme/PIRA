# Writing application

Explicitly assigned scientific writing and human-facing technical prose are in scope, including writing-only assignments. This extends the default worker scope only for those assignments. Apply the accompanying SCIENTIFIC_WRITING guidance to human-facing prose. Preserve the assigned task and edit authority, ownership, and handoff/control-response contract. Machine-readable output, runtime data, code and exact quotations retain their required syntax and semantics; prose style does not override those contracts. Selecting this guidance grants no edit authority.
